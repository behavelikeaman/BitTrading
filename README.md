# btc-signal

BTC 진입 타이밍 점검 메일을 만드는 스크립트입니다. 이 브랜치는 `main`의 앱 코드와 무관한 독립 브랜치입니다.

## 하는 일

4시간 봉 마감마다 실행해서, 일봉 기준 진입 조건과 추적 손절가를 계산하고 HTML 메일로 보냅니다.

- 진입 조건: 90일 고점 대비 -15% 이하, 종가가 20일 저점 대비 +6% 이내, 신저가 당일이 아님
- 수량: 시도당 최대 손실을 시작 자금의 1/3로 고정, 포지션은 잔고의 12배 이하
- 손절: 처음에는 저점의 1% 아래, 이후 매일 최근 7일 최저가의 1% 아래로 올림
- 참고 지표: ETF 순유출입, 펀딩비, 청산 비중, 나스닥, 추정 청산 구간, 단기·중기 추세 (진입 판정에는 쓰지 않음)
- 박스권: 20일 고점·저점으로 박스를 정의하고, 하단 2% 이내 + 반등 봉에서 별도의 작은 롱을 안내 (손절 하단 3% 아래, 목표 박스 중간). 상단 숏은 안내하지 않음

- 급변동 감지: 최근 24시간 1시간 봉에서 등락 2.5% 또는 봉 길이 3.5% 이상(둘 다 평소의 6배 이상)이 나오면 크기와 되돌림 정도를 참고로 표시합니다. `<작업폴더>/news.txt`(한 줄에 `- 요약 | 출처 URL`)가 있으면 원인 뉴스로 붙입니다. 진입 판정에는 쓰지 않습니다
- 별첨: `views.json`에 적은 외부 전문가 의견을 메일 끝에 붙입니다. 의견 속 가격대마다 마지막 4시간 종가가 위·안·아래 중 어디인지 표시합니다. 작성 후 `expires_days`(기본 21일)가 지나면 자동으로 빠지며, 진입 판정에는 쓰지 않습니다

## 실행

```bash
python3 -I btc_signal.py collect <작업폴더>
```

```bash
python3 -I btc_signal.py send <작업폴더> <작업폴더>/note.txt
```

`<작업폴더>/config.json`이 필요합니다. 형식은 `config.example.json`을 보세요. 받는 주소와 잔고 같은 개인 값은 이 저장소에 넣지 않습니다.

차트: `matplotlib`이 설치돼 있으면 추세·박스 차트 PNG를 만들어 메일에 인라인 첨부합니다 (`pip install matplotlib`). 없으면 글로만 보냅니다.

메일은 Resend API로 보냅니다. API 키는 실행 환경이 요청에 붙여 주는 방식을 가정하며, 스크립트에는 키가 없습니다.

## 데이터 출처

- 일봉: Coinbase BTC-USD
- 4시간 봉, 펀딩비, 청산, 미결제약정: OKX
- ETF 순유출입: TFTC
- 나스닥: FRED

## 주의

정해진 규칙의 계산 결과를 알리는 도구이며, 매수·매도 권유가 아닙니다. 추정 청산 구간과 예상 청산가는 가정에 기반한 어림값입니다.
